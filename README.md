Django To-Do List
A simple and elegant To-Do list application built with Django.

Features
✔️ Add, edit, and delete tasks

✔️ Mark tasks as completed

✔️ View tasks by status (completed/pending)

✔️ User-friendly interface

Tech Stack
Backend: Django

Frontend: HTML, CSS (Bootstrap)

Database: SQLite (default)
